Vice Sunset is an offline GTA 6-style cover art maker: drop in your own photos, arrange them across 2–4 slanted poster panels, crop and position each one, write a bold caption, pick a Vice City sunset or neon colour grade, and export a PNG in 1080×1080, 1080×1350 or 1920×1080. Everything runs from static files in your browser — no network, no upload, no Rockstar logo, artwork or font; all lettering and palm/sun art is drawn in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server and open `index.html`.

Vice Cover Studio turns your photos and a caption into GTA-style multi-panel cover art — a hero panel over three strips, a four-panel grid, a full-bleed shot or a nine-panel grid, each with a Vice sunset or neon colour grade, bold poster lettering and a neon subtitle — and exports it as a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080. It runs entirely offline in a desktop browser from its own static files, so your photos never leave your machine; you can crop and reposition every panel by dragging, zoom with the scroll wheel, fill panels from several photos, and edit the title and subtitle live.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Add your photos (or use the built-in sample scenes), pick a layout and grade, edit the caption, and press Export PNG.
